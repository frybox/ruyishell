## 里程碑 M1：shell 透传跑通

目标：`rysh` 能像普通终端一样跑登录 shell。

- [x] Go 项目骨架（go mod init，二进制名 `rysh`）。
- [x] PTY：创建 master/slave（Unix=creack/pty；Windows=ConPTY，建议统一走 `aymanbagabas/go-pty`），clone 子进程挂接 slave，exec 默认 shell。
- [x] 默认 shell 探测：Linux/macOS 取 `$SHELL -l`（登录 shell）；Windows 按 `pwsh` → `powershell` → `cmd` 探测并加载 profile（`shell = "auto"`，可在 `~/.rysh/config.toml` 覆盖）。
- [x] 输入透传：键盘 → pty master → 登录 shell。
- [x] 输出透传：shell 输出 → 屏幕。
- [x] 终端尺寸处理（SIGWINCH）、Ctrl-C 等信号转发（Windows 经 ConPTY 的按键/信号语义不同）。
- [x] 退出/清理逻辑（子进程退出时 rysh 退出）。

**验收**：三平台 `rysh` 内可正常使用全屏/交互程序（Unix 上 vim、git 等；Windows 上 PowerShell 交互与常用全屏工具）。

> 2026-08-24 进度：M1 完成。Linux 实机验证通过（交互 shell、vim 全屏、Ctrl-C 透传、SIGWINCH 尺寸联动、退出码透传、SIGTERM 兜底）；Windows 交叉编译通过（`GOOS=windows`，运行未验证）；macOS 未验证。

## 里程碑 M3：AI 模式与 provider 接入

目标：AI 模式能真实对话、流式输出、切模型。

- [x] `~/.rysh/config.toml`：provider → model 两级配置解析（结构对齐 pi 的 models.json；密钥支持 `$ENV_VAR`/`${VAR}` 环境变量引用，`$$` 转义）。

- [x] AI 回合结束后留在 AI 模式，支持追问。
- [x] `/model` 命令切换模型，即时生效（每次直接读配置文件，改完即生效、无需重启，参考 pi）。
- [x] 模型/密钥配置安全（环境变量引用，不落盘明文）。

**验收**：AI 模式下可多轮追问，`/model` 可切换模型并继续对话。

## 里程碑 M4：工具调用与会话上下文

目标：AI 能执行 shell 命令，shell 输入输出进入 AI 上下文。

- [x] 会话上下文（一）：AI 对话多轮记忆 + `/new` 新建会话（参考 pi 的 `/new`），历史随每轮提示发给模型。（注：v6 起 `/new` 升级为多会话「新建并切换」，见 2026-08-27 v6 进度。）
- [x] Agent 工具调用：执行 shell 命令，记录 cwd/stdin/stdout/stderr/exit_code 并回灌（bash 围栏块 → 独立执行器，输出截断 + 超时杀进程组）。
- [x] cwd 跟踪：登录 shell `cd` 后 rysh 拿到切换结果（Linux `/proc/<pid>/cwd`；macOS/Windows 优先 OSC 7 上报待后续）。
- [x] 环境变量跟踪：每次提问把 shell 环境白名单（`$PATH`、`$HOME`、`$EDITOR` 等常用项）作为 `system` 消息前置给模型（Linux `/proc/<pid>/environ`）；白名单外的变量（密钥/令牌）不泄露给模型。注意：`/proc` 只能看到 shell 启动时的环境，会话内新 `export` 读不到（需 shell hook / OSC 上报，超 M4 范围）。
- [x] 统一事件流：shell 事件与 AI 事件混排（cwd-as-data）。shell 模式下用户执行的每条命令（命令行 + 跟随的终端输出 + 执行时 cwd）被记录进有界事件环（上限 20 条，单条输出 4KB，ANSI 序列剥离），每次提问作为 `system` 消息（最新在前）随 cwd/env/指令一起发给模型，与 AI 对话回合在同一条流中。
- [x] AI 上下文能看到最近的 shell 命令与输出（会话不绑定目录）。每条 shell 事件自带自己的 cwd，agent 看到的目录来自"上次提问时的当前目录 + 各条命令自己的目录"。

**验收**：在 shell 模式 `cd` 到某目录后切 AI 模式，agent 能感知该目录；agent 执行的命令产出进入上下文，用户可追问。

> 2026-08-24 进度：M4 起步——AI 对话多轮记忆已接入（`internal/mode` 提交的任意自然语言草稿进入 `handlePrompt`，把此前 user/assistant 回合拼进请求上下文，回复后回填本轮对话，上限 40 条消息按整轮裁剪）；`/new` 新建会话重置记忆（命名对齐 pi；v6 起升级为多会话「新建并切换」）。cwd 跟踪（Linux `/proc/<pid>/cwd`）已接入：每次提问把当前目录作为 `system` 消息前置给模型（`cwd: <path>`），shell 里 `cd` 后切 AI 模式提问，模型即感知新目录；macOS/Windows OSC 7 上报留待后续。集成测试用 httptest mock 校验：第二轮请求携带第一轮对话 + cwd system 消息、`/new` 后回到单条 user 消息、`cd` 后 system 消息 cwd 与目录一致。下一步：工具调用（agent 执行 shell 命令并回灌输出）。
